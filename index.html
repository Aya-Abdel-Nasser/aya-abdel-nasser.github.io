Commerce Analytics Platform

A multi-source analytics platform integrating PostgreSQL, MySQL, CSV and JSONL inputs into SQL Server, then modeling and validating customer analytics with dbt Core and automated CI testing.

3.4M+Validated synthetic Bronze records
14Bronze tables across 5 source groups

Implemented & validated

  • Multi-source initial ingestion using Informatica Cloud Data Integration into SQL Server Bronze.
  • Source-to-target reconciliation with documented row counts and integrity checks.
  • dbt Core staging, intermediate and Gold models, including customer SCD Type 2 snapshots.

02 — Streaming · Cloud Analytics · MLOpsIntegrated platform

PharmStock AI Platform V2

An end-to-end, synthetic-data pharmacy operations platform connecting CDC streaming, distributed processing, cloud data warehousing, machine learning, human-reviewed operational decisions and business intelligence.

26Raw BigQuery tables documented
26Current-state views documented
4Operational ML models in the platform

Engineering highlights

  • Event-driven CDC: PostgreSQL changes through Debezium and Kafka, processed with Apache Spark.
  • Historical + incremental processing: architecture documents a snapshot-to-CDC cutover with gap protection.
  • Analytics: BigQuery warehouse layers, dbt transformations and Airflow data-quality workflows.
  • MLOps: MLflow model tracking, registry, quality gates and model serving.
  • Governed operations: RBAC, human approval of decisions, evidence-grounded AI assistance, and Power BI reporting.
